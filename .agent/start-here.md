# Start here

Use this restart sequence for every new Little Reef session.

1. Confirm `SoftStrangeStudio/LittleReef`, branch `main`, current remote head, and a clean or understood worktree.
2. Read [repository-profile.md](repository-profile.md) for stable identity and ownership boundaries.
3. Read [memory.md](memory.md) for durable implementation facts and locked constraints.
4. Read [tasks.md](tasks.md), then verify the selected `LR-GH-*` item in the [Production Tracker](https://docs.google.com/spreadsheets/d/1JL1YuEZYvZc9XcoUrJZNIW6dK_iABD8MPgRw6tz1e-o/edit).
5. Use [file-map.md](file-map.md) to locate implementation, coupling, risks, and validation.
6. Run the applicable baseline from [validation.md](validation.md).
7. Perform one bounded task. Preserve unrelated files and protected workflows.
8. Validate the actual outcome, including visual evidence when appearance or interaction changed.
9. Update repository handoff files and the [Drive handoff](https://docs.google.com/document/d/1Kf3Qe6MFSYgtUvxSVywF0n095AQdM7tnPzf9bwwYSRI/edit).

The Production Tracker is authoritative for the full backlog. This folder exists so an agent can restart safely without reopening an old conversation.
