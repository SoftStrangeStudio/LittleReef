# Durable memory

## Current live architecture

- `src/main.js` preloads the configured coral GLBs, then constructs `LittleReefApp`.
- `LittleReefApp` owns scene orchestration, fish entities, UI, menu transition, selection, controls, physics, and the render loop.
- Fish records are data-first and contain a seed, genome, phenotype key, generation, parent IDs, and derived traits.
- Seeded fish genetics and inheritance live in `src/fish/FishGenome.js`; runtime fish records live in `FishService`.
- Fish meshes are generated by the Nexus-derived generator under `src/nexus/fish/` and assembled through `NexusFishFactory`.
- Fish body triangle winding must face outward. The correction is in `src/nexus/fish/generator.js`; do not infer correctness from double-sided rendering.
- The rock arch is deterministic procedural geometry owned by `src/reef/rock-arch/`. It is generated once during reef setup, not per frame.
- Coral is generated offline and shipped as ten static GLBs. The game loads only configured models once, clones shared geometry/materials into deterministic placements, and uses measured collision proxies.
- Default coral IDs are `01`, `03`, `05`, `07`, and `09`; default field count is 18.
- `ReefService.dispose()` delegates coral and arch cleanup. Coral source geometry/materials are disposed once by the shared library.
- Controlled swimming uses `ControlledFishController`, `RoutePlanner3D`, `ObstacleAvoidanceSolver`, `FishCameraRig`, and Cannon-es physics.
- The live game includes a menu-to-reef transition, selectable fish, two-parent breeding, lineage display, goals, procedural audio, schooling, avoidance, the arch, and GLB coral.

## Locked constraints

- Production Tracker is the backlog authority; `.agent/tasks.md` is a small mirror.
- Shared Drive Little Reef is project authority; private My Drive LittleReef is only a review archive.
- Coral remains offline-generated GLB content at runtime.
- Rock arch remains deterministic runtime geometry.
- Central swimming route and arch passage must remain clear.
- Workflow and dependency changes require explicit task scope.
- Headless graphics evidence does not prove real browser input, audio output, or every GPU/driver combination.

## Known gaps

- The frozen Drive design specifies a matrix/state-selector architecture, while the live repository currently uses domain services. That divergence needs an explicit architecture decision before LR-GH-003/004 can be completed.
- Automated fish-genetics, breeding, lineage, mutation, and winding regression coverage is incomplete.
- Nursery capacity, full eligibility rules, save/version migration, keep/sell, economy, and long-term progression are unfinished.
- There is no single aggregate `validate` package script and no repository-owned browser interaction/video harness.
